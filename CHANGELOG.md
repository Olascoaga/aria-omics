# Changelog

All notable milestone releases of **ARIA (`aria-omics`)** are documented here.
`aria/version.py` is the single runtime version source; historical release notes
live under [`docs/releases/`](docs/releases/) and describe the state at each past
tag, whereas [`docs/validation_status.md`](docs/validation_status.md) reflects
current `main`.

## [Unreleased] — `main` (post-`v4.8.0`)

### Highlights
- **Production Cross-Modal RNA $\times$ ATAC Contrast & Sample/Donor Concordance Engine (`ADR-080`, Closing `ADR-028 Slice 2`):**
  - Added `CROSS_MODAL_CONCORDANCE_VALIDATION` (`level="production"`, `evidence_tier="associative"`, `scope="contrast_and_sample_matched_rna_atac_concordance"`, `requires_ack=False`, `production_promoted=True`, `promotion_adr="ADR-080"`), `CrossModalConcordanceAuditAgent` (`green`/`auto` on aligned contrasts; `yellow`/`requires_ack` on `n == 2` low-power designs; `red`/`blocked` on diagonal cell imputation requests, incompatible denominators, `n < 2`, or confounded covariates), and automatic `OrchestratorAgent._run_cross_modal_concordance` execution for `bulk_RNA + bulk_ATAC` and unpaired cohort `scRNA + scATAC` studies while keeping unpaired single-cell diagonal/bridge manifold imputation (`GLUE`, `MultiVI`, `Seurat bridge`) blocked fail-closed (`INTEGRATION_VALIDATION["scope"] == "paired_same_cell_rna_atac"`).
  - Implemented the deterministic cross-modal statistical & figure engine (`aria/utils/cross_modal_concordance.py`, `aria/scripts/cross_modal_concordance.py`, `ScriptContract` at `validation_level="production"`) with `A4` SHA-256 `stage_manifest.json` resume, reversed-contrast sign canonicalization (`B_vs_A` -> `A_vs_B`, stamping `atac_sign_flipped=True`), Layer A 4-quadrant cis DE $\times$ DA concordance (`<= 100 kb` cis + `<= 2 kb` promoter subset, directional + co-significance Fisher exact tests, Spearman $\rho$ / Pearson $r$), Layer B `JASPAR2024` motif + non-descriptive `TOBIAS` differential footprint $\times$ cognate TF RNA triangulation (`::` dimer splitting, `paralog_motif_ambiguity` flags, zero hardcoded TF lists), Layer C RNA/ATAC ORA pathway Jaccard overlap, Layer D `N >= 6` `log2(CPM + 1)` donor/sample-matched cis peak–gene correlation (pooled sample-label permutation BH-FDR + independent held-out permutation diagnostic), 4 CSV supplements, and dual 300-DPI PNG + editable SVG `cross_modal_starburst` figures.
  - Closed `BiologicalSynthesisAgent` Slice 2 (`aria/agents/narrative/synthesis/cross_modal_synthesis.py`), `C3` `ledger://cross_modal/concordance` linkage (`run_ledger.py`), `NarrativeAgent` QC/artifact/Methods reporting, and the 6th deterministic zero-LLM `HypothesisAgent` adapter (`adapters/cross_modal.py`, `CROSS_MODAL_UNPAIRED_COHORT` caveat, shared `chromatin_tf_lineage::<tf>` `independence_key`), validated end-to-end on a 10-donor balanced `GSE278576` human hippocampal cohort (`docs/benchmark_results/multiome_concordance/adr080_cross_modal_concordance_validation.json`, `0` claim-ledger violations, `0` causal verbs).
