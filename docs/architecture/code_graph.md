# Code Dependency & Contract Graph

`docs/architecture/code_graph.md` is the **single authoritative architectural impact and contract map** for ARIA. Consult this document before modifying shared agents, JSON IPC script schemas, claim/ledger governance, environment routing, or report/capsule serialization, and update it whenever a shared contract or dependency edge changes.

## 4. Modality & Cross-Modal Pipelines

### 4.1 Bulk RNA-seq (`BulkRNAAgent` — Matrix & Universal Raw FASTQ `production`, `ADR-075`)
- **Orchestration & Universal Raw FASTQ Engine (`aria-rnaseq-env` / `docker/Dockerfile.rnaseq`):** `aria/agents/bulk_rna_agent.py` + `aria/utils/rna_fastq_protocol.py` routes four short-read bulk families across five `production` IPC scripts with `A4` `stage_manifest` resume:
  - Per-sample (`full_length`, `tag_3prime`, `tag_5prime`, `umi_bulk`): `rna_fastq_qc.py` (`fastp` SE/PE/multi-lane `E4`, poly(X)/poly(G) trimming, optional `--umi` extraction) -> `rna_align.py` (dynamic `_sa_index_nbases` STAR index auto-build, 2-pass `full_length` vs 1-pass soft-clip-preserving tag alignment) -> optional `rna_umi_dedup.py` (directional 1-Hamming `pysam` UMI graph collapse per `(chrom, strand, 5'-anchor)`) -> `rna_quantify.py` (`pysam` indexed/unindexed multi-contig fail-closed strandedness + `featureCounts`).
  - Multiplexed well-barcode + UMI plates (`pooled_plate_bulk`: BRB-seq, DRUG-seq, Prime-seq, QuantSeq-Pool, CEL-Seq2): `rna_starsolo_bulk.py` (`STAR --soloType CB_UMI_Simple --soloUMIdedup 1MM_Directional_UMItools`).
- **Statistical Core & Narrative (`aria-rna-env`):** `aria/scripts/rna_bulk_de.py` + `aria/scripts/rna_bulk/{contrasts,counts,deseq2,gtf_io,ora,plots,qc,transforms}.py`. Enforces total count-column/metadata correspondence (`B5`), sums explicit technical replicates prior to fit (`B1`), runs `pyDESeq2` with `lfcThreshold` inside the Wald test + apeGLM shrinkage + contrast-family BH-FDR (`0` diff on `deseq2.py`), exports `counts_cpm.tsv` and automatically suppresses `TPM` (`counts_tpm.tsv`) on end-tag/UMI protocols due to gene-length bias, links raw preprocessing to `ledger://bulk/preprocessing` (`C3`), and disables free-text LLM result prose (`F3`).
- **Thresholds:** Default `|log2FC| = 1.0` (`ADR-055`), changed only via explicit CP3 profile or `global_lfc`.
- **Guards:** `tests/test_bulk_rna_raw_multiplatform_e2e.py`, `tests/test_bulk_rna.py`, `tests/test_rna_bulk_de_contract.py`, `tests/test_preprint_audit_b4_no_name_fallback.py`, `tests/test_preprint_audit_b5_metadata_correspondence.py`, `tests/test_preprint_audit_e4_bulk_fastq_manifest.py`, `tests/test_preprint_audit_c1_h9_fastq_e2e.py`.

### 4.5 Non-Same-Cell Cross-Modal Contrast & Sample/Donor Concordance (`ADR-080`, Closing `ADR-028 Slice 2`)
- **Scope & Gates (`ADR-028`, `ADR-080`):** `CROSS_MODAL_CONCORDANCE_VALIDATION` (`level="production"`, `evidence_tier="associative"`, `scope="contrast_and_sample_matched_rna_atac_concordance"`, `production_promoted=True`, `requires_ack=False`) + `CrossModalConcordanceAuditAgent` (`green`/`auto` on aligned RNA $\times$ ATAC contrasts; `yellow`/`requires_ack` on `n == 2` low-power contrasts; `red`/`blocked` on diagonal cell imputation requests `diagonal_cell_imputation_not_validated`, incompatible denominators, `n < 2` contrasts, or confounded covariates). - **Statistical & Figure Engine (`stack="rna"`, `aria/utils/cross_modal_concordance.py` + `aria/scripts/cross_modal_concordance.py`):**
  - Contrast canonicalization (`A_vs_B` vs reversed `B_vs_A` negates ATAC `log2FC`, motif enrichment direction, and `TOBIAS` footprint change while stamping `atac_sign_flipped=True`; refuses incompatible denominators `A_vs_B` vs `A_vs_C`).

  - **Layer C:** Functional pathway intersection (`RNA ORA` $\cap$ `ATAC peak_ora`) with Jaccard overlap index.
  - **Layer D:** Sample/donor-matched cis peak–gene correlation (`N >= 6` shared biological units, `log2(CPM + 1)`, pooled sample-label permutation BH-FDR + independent held-out permutation diagnostic; honest skips `insufficient_matched_biological_units` / `unmatched_sample_namespaces`).

- **Synthesis, Ledger & Reporting (`C3` / `C4`):** `aria/agents/narrative/synthesis/cross_modal_synthesis.py` (`BiologicalSynthesisAgent` Slice 2: engine-backed + deterministic in-memory fallback, 100% `W-CLAIM` and zero-causal-verb compliant), `ledger://cross_modal/concordance` (`run_ledger.py`), and `NarrativeAgent` QC summary row, figure/table staging, and HTML-safe Methods paragraph.
