# ARIA Architecture Decisions

## ADR-001 - LLM Proposes, Code Guarantees

Status: accepted

Scientific invariants cannot depend on model prose.

Implications:

- Contrasts are generated by deterministic code.
- Thresholds are enforced by code.
- Resume/cache validity is checked by files and parameter signatures.
- Reports are grounded in structured outputs.

## ADR-002 - No Silent Fake Science

Status: accepted

Missing dependencies or failed analyses must not produce fake scientific
outputs.

Implications:

- Mocks require explicit development/test opt-in.
- Missing results stay missing.
- Partial failures are surfaced in reports.
- Raw exception dictionaries should be translated into human-readable report
  text, not hidden or rendered as Python objects.

## ADR-003 - Resume By File Validity

Status: accepted

In-memory flags are not durable enough for large analyses.

Implications:

- Heavy steps validate output files and parameter signatures.
- Legacy or mismatched outputs rerun.
- Intermediate ARIA h5ads are ignored when real source h5ads are present.

## ADR-004 - Explicit, Auditable Decisions

Status: accepted

Methodology must be reviewable.

Implications:

- Parameter decisions are logged.
- Methods sections include formulas, thresholds, covariates, groupby columns,
  and warnings.
- Defaults that affect science should be visible in reports.

## ADR-005 - Dataset-Agnostic Runtime

Status: accepted

Runtime prompts, heuristics, and narrative guardrails must not hardcode
validation datasets, genes, perturbations, or domain-specific rescue phrases.

Implications:

- Validation datasets may be documented in README/docs/tests.
- Runtime code must use generic biological and statistical rules.
- Anti-causality guardrails operate on language patterns, not specific genes.

## ADR-006 - Pseudobulk Carries scRNA Condition Inference

Status: accepted

For condition contrasts in scRNA-seq, donor/sample-level pseudobulk carries the
main inferential weight.

Implications:

- Cell-level Wilcoxon marker discovery is optional on atlas-scale inputs.
- A timeout in per-cluster marker discovery does not invalidate completed
  pseudobulk, pathway, communication, and trajectory outputs.
- Reports must clearly distinguish marker discovery from condition DE.

## ADR-007 - Trajectory Is Exploratory Without Velocity/Time Course

Status: accepted

PAGA/DPT describes manifold connectivity and ordering, not active
differentiation.

Implications:

- Reports must avoid lineage-causality claims unless velocity or time-course
  evidence exists.
- RNA velocity is skipped unless spliced/unspliced layers are present.

## ADR-008 - Raw Ingestion Is A Deterministic Pre-Pipeline Layer

Status: accepted

Users should not have to leave ARIA to turn standard raw scRNA inputs into a
canonical `.h5ad`, but raw ingestion must not weaken ARIA's scientific
guarantees.

Implications:

- Raw ingestion is owned by a `RawIngestionAgent` plus deterministic
  `IngestionEngine`, not by large ad hoc branches inside `SetupAgent`.
- `DataAuditAgent` detects raw input formats and validates base integrity
  before ingestion.
- Cell Ranger-style 10X matrix triplets are converted with
  `scanpy.read_10x_mtx` into workspace `.h5ad` files.
- FASTQ ingestion is explicit: ARIA detects and groups FASTQs, then requires
  chemistry, organism/genome or transcriptome, local index path, index hash,
  and quantifier versions before execution.
- External quantification commands, first via `kb-python`, must be recorded
  exactly with source hashes, output hashes, reference/index hashes, versions,
  and parameter hashes.
- ARIA never downloads references silently, guesses chemistry silently,
  fabricates matrices, or merges samples unless grouping is unambiguous.

## ADR-009 - Narrative Depth Is Deterministic And Result-Local

Status: accepted

Scientific report depth should come from structured pipeline outputs, not from
free-form model extrapolation.

Implications:

- Narrative modules should interpret each major result block locally before
  writing broad synthesis.
- scRNA pseudobulk narrative must surface top blocks with global/local FDR,
  top up/down genes, composition-correction status, power estimates, ORA
  support, and explicit caveats when present.
- Differential abundance, pathway ORA, LIANA, and trajectory sections should
  connect their evidence to the specific result blocks they support, while
  preserving causality and confidence guardrails.
- LLM prose may polish wording only after deterministic summaries exist; it
  must not decide which analyses ran or invent biological interpretation.
- New modality narrative modules such as `_narrative_chromatin.py` should
  follow the same result-local pattern.
