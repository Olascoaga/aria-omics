## 4. Fix A+B+C (commit `b0f6a90`) + path correction (`37407e5`) + hotfix (`59aa0c8`)

### Fix A — Hard-stop unrecoverable matrices

`_annotate_cell_types` retorna `annotation_source="unrecoverable_matrix"` con
`Confidence.LOW` cuando CellTypist devuelve `InvalidExpressionMatrix` o
`NoUsableCountsOrLogNorm`. Sin LLM-only fallback ruidoso.

`_run_pseudobulk` skip cuando `cell_type_col=="leiden"` Y annotation falló.

### Fix B — Respetar anotación pre-existente

Mi versión inicial aplicaba `cluster_col` después de sketch + neighbors + UMAP +
Wilcoxon. Eso destruía cells (sketch a 100k) y rompía pseudobulk per donor.

**Codex corrigió** en `rna_clustering.py:114-166`: **early-return** cuando
`use_predef_clusters=True`, ANTES de sketch/preprocessing/Wilcoxon:
- Preserva TODAS las cells (1.1M intactas)
- Normaliza NaN/empty → "Unassigned" (no dropea)
- Output `clustered.h5ad` (no sketch)
- `top_markers={}` vacío (markers no se recomputan)
- `warnings=["Leiden clustering skipped; ... Marker genes were not recomputed in this fast path."]`

`scrna_agent` lado:
- `_predefined_celltype_col(h5ad, exp_ctx)` valida col en obs viva
- `_annotation_from_obs` construye findings.cell_types desde obs sin LLM ni CellTypist
- `run()` rutea: clustering recibe `cluster_col=subclass`, annotation va a `_annotation_from_obs`

### Fix C — sample_id hardening

`_sample_id_from_path` strip `qc_filtered_` prefix + rechaza ARIA intermediate
stems (`annotated`, `clustered`, `qc_filtered`, etc.) con hash fallback.
Workspace de 81 GB borrado por Samael antes del rerun.

### Narrative grouping fix (commit `37407e5`)

`_narrative_scrna.py`:
- Helper `_group_label(groupby, n)` centraliza plural ("cell type"/"cell types",
  "Leiden cluster"/"Leiden clusters", "subclass group"/"subclass groups")
- `summarize_scrna_text` branch para `predef_clusters=True`: "reused N subclass
  groups from input obs['subclass']; Leiden clustering was skipped."
- `build_scrna_methods` mismo branch
- Trajectory caveat suavizado: "exploratory manifold connectivity; not proof of
  active differentiation without velocity or time-course data"
- Fix typo `subclasss` (triple s) que venía de `f"{groupby}s"`

`narrative_agent.py` exec summary: detecta predef y emite "X subclass groups
from obs['subclass']" en lugar de "X Leiden clusters".

`rna_narrative_adapter.py` propaga `groupby` y `predef_clusters` al harness.

### Post-tag hotfix narrativo (`59aa0c8`, mío)

`_narrative_scrna.summarize_scrna_text` y `narrative_agent._summarize_rna`
ahora surface `findings.differential_expression.status != "success"`:

```
Body: "Per-cluster marker discovery (Wilcoxon) did not complete (Timeout:
       Execution exceeded 3600s limit.). Cluster-marker TSV is unavailable
       for this run; cell-type identities and between-condition results
       below come from independent paths (input obs labels and/or
       pseudobulk DE) and remain valid."

Exec: "Per-cluster marker discovery did not complete (Timeout); pseudobulk
       DE below is the primary differential-expression signal."
```

Razón: en el rerun TUI 14:33 Wilcoxon per cluster timeó out a los 3600s pero el
report no lo mencionaba. Eso violaba "Missing Results Stay Missing".

Test cubre: `"Per-cluster marker discovery" in summary`, `"Timeout" in summary`,
y que pseudobulk siga mencionado como signal válido.

### Report fidelity hotfix (`805e0b2`, tagged `v4.3.12.post1`)

- HTML report version now reads from `aria.__version__`, not `v0.2`.
- Methods and Parameter Decisions Log are HTML-escaped, fixing dropped text such
  as `<10 counts`.
- Raw Python error dictionaries in findings are converted to human-readable
  text, e.g. integration skipped because fewer than two modalities exist.
- LIANA tables no longer show a generic all-zero-looking "Score" column.
  They show rank, metric value, and the metric name (`specificity_rank`, etc.).
- Top L-R plot uses rank when available.
- Bulk interpretation gets a generic anti-causality caveat.

### Dataset-specific guardrail removal (`d3de169`)

Samael correctly flagged that the first anti-causality guardrail referenced
specific genes/analyses. Runtime code must never be hardcoded to a validation
dataset.

Changes:
- Removed dataset-specific gene/perturbation examples from runtime prompts and
  docstrings.
- Removed gene-specific genome detection heuristic.
- Replaced gene-specific bulk interpretation replacements with generic causal
  language patterns: `acts as`, `position X as`, `X enforces Y`, `X drives Y`.
- Smoke test uses `GeneA/GeneB`, not real validation genes.
- Verified no runtime mentions in `aria/` or new smoke tests for validation
  genes, circadian/pluripotency terms, or `transcriptional repressor`.
